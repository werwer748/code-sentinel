# 보고서: 경로 따옴표 규칙 (C 스타일)

발견 항목 위치(`findings.md` 3절)의 경로에 아래 문자가 하나라도 있을 때만 읽습니다. 헤더 문법과 마찬가지로 채점 스크립트와 공유하는 계약입니다.

## 1. 감싸는 경우

경로에 다음 중 하나라도 들어 있으면 경로 전체를 큰따옴표로 감싸고 내부를 이스케이프합니다. 이름 변경은 두 경로를 각각 판단합니다.

- 제어문자(U+0000~U+001F, U+007F)
- 역슬래시 `\`
- 큰따옴표 `"`
- 부분 문자열 ` · ` (공백·가운뎃점·공백)
- 부분 문자열 ` → ` (공백·화살표·공백)

## 2. 이스케이프 (Git의 C 스타일 표기와 같음)

| 문자 | 표기 |
|---|---|
| 역슬래시 | `\\` |
| 큰따옴표 | `\"` |
| 개행 / 탭 / 캐리지 리턴 | `\n` / `\t` / `\r` |
| 벨 / 백스페이스 / 폼 피드 / 수직 탭 | `\a` / `\b` / `\f` / `\v` |
| 그 밖의 제어문자 | 8진수 세 자리 `\ooo` (예: U+001B → `\033`) |

- 한글, 공백, 단독 가운뎃점·화살표, 그 밖의 비ASCII 문자는 이스케이프하지 않고 그대로 씁니다. 따옴표가 필요 없는 경로는 감싸지 않습니다.
- 매니페스트에 따옴표 표기로 나온 경로는 디코딩한 실제 경로를 기준으로 이 규칙을 다시 적용합니다.

## 3. 예

| 실제 경로 | 헤더 |
|---|---|
| `src/주문 처리/api.ts` | `[S-01] High · 확신도 High · security · src/주문 처리/api.ts:10-12` (감싸지 않음) |
| `src/a"b.ts` | `[S-02] Medium · 확신도 Medium · correctness · "src/a\"b.ts":3` |
| `src/back\slash.ts` | `[S-03] Medium · 확신도 High · ops · "src/back\\slash.ts":3-5` |
| `src/line` + 개행 + `break.ts` | `[S-04] Low · 확신도 High · readability · "src/line\nbreak.ts":1` |
| `docs/a · b.md` | `[S-05] Low · 확신도 Medium · style · "docs/a · b.md":4-6` |
| `src/a → b.ts` | `[S-06] High · 확신도 Low · performance · "src/a → b.ts":2` |
| 이름 변경 `src/a → b.ts` → `src/c.ts` | `[S-08] Low · 확신도 High · tests · "src/a → b.ts" → src/c.ts:1-3` |
