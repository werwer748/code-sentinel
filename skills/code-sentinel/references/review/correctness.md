# `correctness` — 정확성 및 버그

이 영역을 검토할 때 읽습니다. 공통 원칙은 `principles.md`, 심각도·확신도 정의와 보고 규칙은 `severity.md`를 따릅니다. 각 영역 문서는 다른 영역 문서 없이 쓸 수 있게 독립적으로 작성했습니다.

## 확인 항목

**조건문과 경계**
- off-by-one, `<`와 `<=` 혼동, 빈 컬렉션·0·음수·최댓값 처리
- falsy 값(`0`, `""`, `false`)과 null/undefined를 같은 것으로 취급
- 부정 논리 실수(`!a || !b`와 `!(a || b)`), 단락 평가로 실행되지 않는 부수 효과
- `switch`의 fall-through, 새 enum 값에 대한 분기·`default` 누락

**상태 관리**
- 초기화 누락, 공유 가변 상태, 재진입 시 남은 상태
- 상태 전이 누락(취소·실패 상태로 가는 경로), 캐시와 원본 불일치

**입력 검증**
- 외부 입력(요청, 파일, 환경변수, 메시지)의 타입·범위·형식·길이 검증 누락
- 단위 혼동(초와 밀리초, 원과 센트), 인코딩(UTF-8, 정규화)

**날짜·시간**
- 타임존 혼동(로컬 vs UTC), DST 전환, 월 0-index, 문자열로 날짜 비교
- 만료·기간 계산의 경계, 서버와 클라이언트 시계 차이

**잘못된 참조**
- null/undefined 역참조, 존재하지 않을 수 있는 키·인덱스 접근
- 이름 변경·삭제 후 남은 호출부, 시그니처 변경에 맞춰지지 않은 호출부
- 잘못된 변수·복사 붙여넣기 실수(비슷한 두 블록에서 하나만 수정)

**예외 처리**
- 예외를 삼키고 성공처럼 진행(빈 `catch`, 로그만 남기고 200 반환)
- 너무 넓은 `catch`로 다른 오류까지 잡음, 오류 후 정리(`finally`, `defer`, `close`) 누락
- 비동기: `await` 누락, 처리되지 않은 Promise 거부, 콜백 이중 호출

**데이터 정합성**
- 여러 단계의 쓰기에 트랜잭션 없음, 부분 실패 시 불일치
- 금액·수량의 부동소수점 계산, 반올림 규칙, 정밀도 손실
- 정렬·페이지네이션의 불안정성(동점 처리 없음)

**동시성**
- 확인 후 처리(check-then-act) 경쟁 상태, 락·원자적 연산 누락
- 중복 실행·이중 처리, 공유 자원의 비동기 동시 수정

**접근성 기능 결함 (`principles.md` 0.6절)**
- 클릭 가능한 `div`·`span`(키보드 조작·역할 없음), 라벨 없는 입력, 모달·라우트 전환 시 포커스 유실, 색상만으로 전달하는 상태, 낮은 대비

**선언된 의도 대비 구현 (`principles.md` 0.5절)**
- 커밋 메시지·PR 본문·사용자 설명이 말한 동작의 누락·불일치·범위 밖 동작 변경

## 흔한 오탐 (보고하지 않음)

- 타입 시스템이나 앞선 검증으로 이미 보장된 null 가능성
- 호출부를 확인해 실제로 도달할 수 없는 경계 조건(이 경우 근거를 확인한 뒤 판단)

## 심각도 예시

판단 기준을 맞추기 위한 예시입니다. 실제 심각도는 `severity.md` 1.1절의 요소로 조정합니다.

| 심각도 | 예시 |
|---|---|
| Critical | 트랜잭션·락 없이 잔액을 확인한 뒤 차감해 동시 요청으로 음수 잔액·이중 출금 발생 |
| Critical | 멱등키 없이 외부 결제를 재시도해 타임아웃 시 고객에게 이중 청구 |
| High | 예외를 삼키고 200을 반환해 결제 실패를 성공으로 처리하고 주문 확정 |
| High | 새 NOT NULL 컬럼을 기본값 없이 추가한 직후 그 컬럼을 읽는 코드가 배포돼 기존 행에서 오류 |
| High | 모달이 열려도 포커스가 이동하지 않고 닫기 버튼이 `div onClick`이라 키보드 사용자가 결제 단계에서 진행 불가 |
| Medium | 타임존을 로컬 기준으로 계산해 자정 근처 주문의 날짜가 하루 어긋남 |
| Medium | 검색 요청의 늦은 이전 응답이 최신 결과를 덮어써 잘못된 목록 표시 |
| Medium | 라벨 없는 입력 필드로 스크린 리더 사용자가 필드 용도를 알 수 없음 |
| Low | 빈 배열일 때 "0건" 대신 빈 문자열 표시 |
| Low | 커밋 메시지는 "로그 메시지 수정"인데 로그 레벨도 함께 바뀜(동작 영향 미미) |
